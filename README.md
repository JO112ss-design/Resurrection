# Resurrection

Minecraft 26.3 / NeoForge 用の蘇生MOD。

## 仕様

- プレイヤーが死亡すると、その場で**発光して倒れた状態（ダウン）**になる
- ダウン中は移動・攻撃・ブロック操作・アイテム使用ができず、通常のダメージも受けない
- 他のプレイヤーがダウンした仲間の **2.5ブロック以内でしゃがみ続ける**と蘇生の詠唱が始まる
  - **10秒**しゃがみ続けると蘇生完了（途中で立つ・離れるとリセット）
  - 蘇生した側は**経験値20レベル**を消費（クリエイティブは無料）
  - 蘇生されたプレイヤーは体力3ハートで復帰
- ダウンから **180秒** 経過すると、そのまま死亡する
- ダウン中に**しゃがみを3秒長押し**すると諦めて死亡できる

### 補足ルール

- クリエイティブ・スペクテイターはダウンしない
- 不死のトーテムが発動する場合はトーテムが優先
- 奈落や `/kill` などは、ダウン中でもそのまま死亡
- ダウン中にログアウトすると死亡扱い（サーバー停止時は除く）

### テスト用コマンド（OP権限 / シングルは「チートの許可」をオン）

- `/resurrection down [プレイヤー]` … 死なずにダウン状態にする
- `/resurrection revive [プレイヤー]` … 経験値なしで即蘇生する

数値は `DownedManager.java` 冒頭の定数で変更できます。

## ビルド

```
./gradlew build
```

`build/libs/` に jar ができます。GitHub Actions でも push ごとにビルドされ、Actions の実行結果から `resurrection-jar` をダウンロードできます。
